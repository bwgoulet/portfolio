# AGENTS.md

This file defines default working instructions for future coding sessions in this repository.

## Project runbook
- Install dependencies: `npm install`
- Start dev server: `npm run dev`
- Default local URL: `http://localhost:3000`
- Preferred viewport for visual QA: **desktop** (use a desktop-sized viewport, e.g. 1440x900)

## Visual verification expectations
When making UI/scene/animation/layout changes:
1. Run the app locally.
2. Validate the changed behavior in the browser at desktop viewport.
3. Capture before/after screenshots when tooling allows.
4. Summarize what was visually verified in the final report.

## Notes for agents
- If execution is restricted by the session policy, clearly state the limitation and provide a manual verification checklist.
- Prefer small, testable changes and report exact commands used.
